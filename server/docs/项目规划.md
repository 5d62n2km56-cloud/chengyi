# 轻量版后端规划

目标：通过 Dify Agent 为非遗物品提供介绍、局部讲解和连续问答，并接入声音交流。首版语音为按住说话、松开发送。

## 三个业务板块

| 板块 | 内容 |
| --- | --- |
| 非遗资料 | 物品、部位、补充资料、出处、录入与发布 |
| 大模型讲解与问答 | Dify Agent、知识库上下文、连续问答、语音识别及分句合成 |
| 前端交互接口 | 物品与部位点击、文字和音频流、录音转写、声音播放指令 |

管理页面只有大模型接入、非遗资料两个入口，声音配置位于大模型页面。会话凭证、管理登录、错误处理与调用记录在内部保留。

## 当前进度

2026-10-15 已完成 Dify 旧版 Agent 和硅基流动声音接入，真实接口与浏览器播放测试通过，36 项自动测试通过。支持资料选择、部位追问、文字流、分句 MP3、短 WAV 转写以及暂停继续重播的指令识别。已注册 C001 青花缠枝莲纹碗与部位入口供联调。

接下来由正式前端对接录音、播放和展示效果，人工验证麦克风与手机兼容性。识别准确率需要使用项目中的实际藏品名称检验，当前已有同音错字；语音自动切换物品尚未实现。正式数据库由项目负责人提供，后端创建表或适配既有结构。

暂缓路线导航、统计看板、用户注册、复杂权限、多语言、持续收音与实时双向语音。MySQL/PostgreSQL 和服务器部署等待实际环境联调。

## 分工

后端负责数据表、接口、会话上下文、Dify 调用、录音转写、声音合成和预设播放指令识别；前端负责物品展示、按住录音、权限提示、文字显示、音频队列、播放控制与动画动作；项目负责人维护 Dify 模型、Prompt、知识库资料及默认识别模型，并提供正式数据库。
